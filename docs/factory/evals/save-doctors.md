# save-doctors

Let patients save doctors.

Add storage for saved doctors and a new screen that lists them. A person can save a doctor from the doctor card and open the saved list later.

Do not use a real person's name, number, or history. Use fixture names only.

Acceptance:

- Saving a doctor keeps it after the screen closes.
- The new screen lists the saved doctors.
- Removing a doctor takes it off that list.
