# wallet-transactions

Make the Wallet Transactions screen easier to use.

Add a filter, a refresh, a clear error when the list fails to load, and a skeleton while it loads. Keep the existing list.

Do not use a real person's name, number, or history.

Acceptance:

- The screen can filter the list.
- Refresh loads the list again.
- A failed load shows an error, not a blank screen.
- The first load shows a skeleton.
